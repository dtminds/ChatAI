# 智能表格写入节点

## 当前范围

节点为 `runtime-ready`：编辑、草稿保存、执行配置投影、Runtime 和 Worker 的真实 Webhook Adapter 已接通。真实企微 Webhook 联调尚未执行。

## 编辑交互

- 节点设置面板沿用发券节点的摘要样式，显示智能表格地址（未填写或点此查看）、Webhook 和编辑入口，不显示已选字段数量或 Schema。字段值映射保留在下方。
- 首次配置在弹窗中填写 Webhook URL、示例数据；表格地址选填，提示「建议填写，方便打开表格查看」。
- 表格地址仅用于识别和打开目标表格，支持 HTTP / HTTPS，不作为 webhook 请求地址。它保存在 Draft 的 `tableUrl`，不进入 Execution Config 或变量目录。
- 同一个弹窗始终展示表格地址和 Webhook，字段选择区不提供搜索。首次默认不选，最多勾选 20 个字段，不截断目录；不支持的字段展示为禁选项。
- 达到上限后禁止新增勾选，但可取消已选字段。至少选择一个字段才能确认，字段值可以在确认后继续填写。
- 再次打开直接回显字段选择；通过标题右侧「同步字段」将字段列表替换为 Schema 输入框和解析按钮，解析成功后回到字段列表。同步过程中未解析或解析失败时不能确认，旧节点配置不受影响。
- 编辑示例数据时，底部左侧显示 Webhook 推送文档链接，不显示已选字段数量；回到字段选择后恢复已选数量。
- 已有字段列表时编辑示例数据，底部右侧显示「返回」「解析」；返回会放弃未解析的示例数据修改，解析成功后回到字段选择。首次配置且没有已解析字段列表时仅显示「解析」。字段选择时底部右侧显示「取消」「确认」。
- 相同字段 ID 和类型保留原值、更新名称；新增字段默认不选；删除或变为不支持类型的字段取消选择并提示；类型改变的已选字段保留选择、清空原值并提示。
- 所有弹窗修改仅在点击「确认」后一次性写入节点，并由既有草稿流程保存。取消、关闭或 Escape 均丢弃本次弹窗修改。
- 填写有效表格地址后，面板显示「点此查看」，在新标签页打开；可重新编辑或清空地址。

Schema 原文最多 100,000 字符，完整目录从 Schema 恢复，不另存一份目录。解析为本地操作，不发起逐字段请求。固定值最多 10,000 字符。

## 字段和输出

支持 `text`、`number`、`date_time`、`single_select`、`checkbox`、`url`。URL 字段直接写入链接对象，不下载远程资源；日期和选项固定值使用相应选择器，变量按类型过滤。

目前注册的节点输出为 `success: boolean`，未注册 `errorMessage`。节点时间沿用公共生命周期属性。

## 运行语义

- 每次节点执行提交一个 `add_records`，新增一行；只接受 HTTPS 企微智能表格 Webhook 地址和非空 key。
- 空字符串、纯空白和 null 跳过；保留 0 与 false。全部为空、类型错误、缺失变量、依赖查询失败或企微拒绝均输出 `success=false`，通过 default 出口继续。流程取消、任务过期及 Live Revision 不兼容仍由公共运行保护处理。
- 单选按配置中的 enumOptions 校验，不存在的选项跳过，不主动创建企微选项。
- 日期按企微日期字符串或毫秒时间戳字符串传输，本地日期时间按 UTC+8，带时区时间转换为毫秒时间戳。
- URL 字段按企微 `CellUrlValue` 写入 `[{link, text}]`，当前将链接地址同时作为跳转地址和展示文本，不发起 URL 请求。
- Webhook 请求使用标准 `fetch`，只对 Webhook 地址校验 HTTPS、固定企微域名、路径和 key；不自定义 DNS、IPv4/IPv6 或 socket 连接逻辑。
- POST 不重试，包括超时、连接断开、HTTP 错误和无法解析的响应。Runtime 在进入 Adapter 前持久化尝试标记；崩溃恢复后返回 `success=false`，不重发。标记落库后、实际发送前崩溃会放弃本次写入；已写入但结果未提交时也可能报告失败，不承诺 exactly-once。
- 智能表格URL仅为草稿备注，不参与执行；Webhook key 不进入节点输出或远端错误日志。

## 验证边界

覆盖配置与变量校验、字段转换、失败继续、超时取消、持久化标记失败、崩溃恢复不重发、Live Revision 上下文检查及 URL 写入。真实企微联调和 MySQL 集成测试未执行；持久化恢复测试使用已有内存仓库，不能替代真实数据库并发验证。
